## 🧩 About

**Far Cry 6 catalog Menu** is a curated list of Far Cry 6 open-source tools:

- **Overlays** — on-screen helpers, layout notes, minimap enhancer, objective tracker
- **Quality-of-Life Helpers** — inventory catalog, weapon skin manager, overlay notes
- **Research Notes** — mission layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Mission Helpers
- Objective Tracker — enhanced quest markers and progress notes
- Minimap Overlay — larger map with loot and checkpoint icons
- Route Notes — record and review mission paths
- Time-of-Day Control — adjust environment lighting for study

### 🎨 Catalog & Cosmetics
- Weapon Catalog — browse weapons, attachments, and skins
- Custom Skin Notes — organize gear cosmetics
- Visual Enhancer — improved clarity for exploration

### 🏋️ Exploration Layout
- Fast Travel Notes — plan efficient travel routes
- Resource Locator — highlight collectible resources
- Stealth Indicator — visual feedback for detection state
